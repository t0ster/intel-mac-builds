# intel-mac-builds

Builds for Intel macOS (x86_64) that upstream no longer publishes. Each build is a
[GitHub release](https://github.com/t0ster/intel-mac-builds/releases) whose notes give
the source, build command, and SHA-256. Upstream licenses apply to each artifact.

| Release | Artifact | Requires |
|---|---|---|
| `torchvision-0.29.1` | `torchvision-0.29.1-cp314-cp314-macosx_15_0_x86_64.whl` | macOS 15+, Python 3.14, torch 2.14.x ([community build](https://github.com/Morton-Li/PyTorch-MacOS-Builder)) |
